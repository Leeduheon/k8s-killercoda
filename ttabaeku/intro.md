# 따배쿠 쿠버네티스 실습 환경

터미널이 열리면 자동으로 아래 설정들이 완료됩니다:
* `k` (`kubectl` 단축 명령어) + **Tab 자동완성**
* `kgp` (파드 조회), `kgn` (노드 조회), `kgs` (서비스 조회), `kgd` (디플로이먼트 조회)
* `$do` (`--dry-run=client -o yaml`), `$now` (`--force --grace-period=0`)
* `kn <네임스페이스>` (기본 네임스페이스 즉시 변경)
* `~/k8s-killercoda` 폴더에 따배쿠 실습 파일 자동 다운로드 완료
